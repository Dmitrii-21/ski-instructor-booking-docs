# Функциональные требования

## Онлайн-запись клиента

| ID | Требование | Связанный UC | Приоритет |
|---|---|---|---|
| FR-001 | Система должна позволять клиенту выбрать категорию инструктора: лыжи, сноуборд или универсал | UC-001 | Must |
| FR-002 | Система должна отображать список услуг, доступных для выбранной категории инструктора | UC-001 | Must |
| FR-003 | Система должна позволять клиенту выбрать услугу занятия | UC-001 | Must |
| FR-004 | Система должна отображать варианты длительности занятия и количества участников | UC-001 | Must |
| FR-005 | Система должна позволять клиенту выбрать вариант занятия: длительность и количество участников | UC-001 | Must |
| FR-006 | Система должна отображать список инструкторов и доступные временные слоты по датам | UC-001 | Must |
| FR-007 | Система должна позволять клиенту выбрать инструктора и временной слот | UC-001 | Must |
| FR-008 | Система должна создавать черновик записи после выбора слота | UC-001 | Must |
| FR-009 | Система должна резервировать выбранный слот на 15 минут со статусом `hold` | UC-001 | Must |
| FR-010 | Система должна отображать форму ввода данных клиента после резервирования слота | UC-001 | Must |
| FR-011 | Система должна требовать заполнения обязательных полей: ФИО, телефон, уровень катания и согласие с пользовательским соглашением | UC-001 | Must |
| FR-012 | Система должна позволять клиенту указать необязательные данные: возраст, e-mail и комментарий | UC-001 | Should |
| FR-013 | Система должна выполнять финальную проверку доступности слота перед подтверждением записи | UC-001 | Must |
| FR-014 | Система должна атомарно переводить запись в статус `confirmed` при успешном подтверждении | UC-001 | Must |
| FR-015 | Система должна делать созданную запись видимой инструктору в его расписании | UC-001 | Must |
| FR-016 | Система должна делать созданную запись видимой администратору в интерфейсе управления сменой | UC-001 | Must |
| FR-017 | Система должна отправлять уведомление о созданной записи | UC-001 | Should |

## Обработка альтернативных сценариев

| ID | Требование | Связанный UC | Приоритет |
|---|---|---|---|
| FR-018 | Система должна снимать резерв слота, если клиент не завершил запись в течение 15 минут | UC-001 | Must |
| FR-019 | Система должна возвращать слот в список доступных после истечения резерва | UC-001 | Must |
| FR-020 | Система должна сообщать клиенту, если при финальной проверке слот стал недоступен | UC-001 | Must |
| FR-021 | Система должна возвращать клиента к выбору слота, если выбранный слот стал недоступен | UC-001 | Must |
| FR-022 | Система должна сохранять запись даже при ошибке отправки уведомления | UC-001 | Should |
| FR-023 | Система должна показывать сообщение об ошибке отправки уведомления, если запись создана, но уведомление не отправлено | UC-001 | Should |

## Расписание инструктора

| ID | Требование | Связанный UC | Приоритет |
|---|---|---|---|
| FR-024 | Система должна позволять инструктору открыть раздел «Расписание» | UC-002 | Must |
| FR-025 | Система должна отображать календарь инструктора по дням или неделям | UC-002 | Must |
| FR-026 | Система должна отображать слоты и занятость инструктора | UC-002 | Must |
| FR-027 | Система должна позволять инструктору выбрать дату или интервал | UC-002 | Must |
| FR-028 | Система должна отображать список занятий инструктора с временем начала, временем окончания, услугой и статусом | UC-002 | Must |
| FR-029 | Система должна позволять инструктору открыть карточку занятия | UC-002 | Must |
| FR-030 | Система должна отображать детали занятия: ФИО клиента, телефон, уровень катания, возраст, комментарий и место встречи при наличии | UC-002 | Must |
| FR-031 | Система должна показывать состояние «Нет записей», если на выбранную дату занятий нет | UC-002 | Should |

| ID | Требование | Связанный UC | Приоритет |
|---|---|---|---|
| FR-032 | Система должна позволять администратору открыть раздел «Создать запись» | UC-003 | Must |
| FR-033 | Система должна отображать список инструкторов смены на текущий день | UC-003 | Must |
| FR-034 | Система должна отображать доступные слоты инструкторов на текущий день | UC-003 | Must |
| FR-035 | Система должна позволять администратору выбрать параметры занятия клиента | UC-003 | Must |
| FR-036 | Система должна позволять администратору выбрать инструктора и слот | UC-003 | Must |
| FR-037 | Система должна резервировать слот при создании записи администратором | UC-003 | Must |
| FR-038 | Система должна позволять администратору ввести данные клиента | UC-003 | Must |
| FR-039 | Система должна позволять администратору подтвердить создание записи | UC-003 | Must |
| FR-040 | Система должна отображать созданную запись в расписании инструктора и списке записей смены | UC-003 | Must |
| FR-041 | Система должна отправлять уведомление инструктору о новой записи, созданной администратором | UC-003 | Should |

## Управление доступностью инструктора

| ID | Требование | Связанный UC | Приоритет |
|---|---|---|---|
| FR-042 | Система должна позволять администратору открыть раздел «Смены/доступность» | UC-004 | Must |
| FR-043 | Система должна позволять администратору выбрать инструктора и дату или период | UC-004 | Must |
| FR-044 | Система должна отображать текущую доступность инструктора: рабочие часы, перерывы и блокировки | UC-004 | Must |
| FR-045 | Система должна позволять администратору добавлять и редактировать смены инструктора | UC-004 | Must |
| FR-046 | Система должна позволять администратору добавлять и редактировать блокировки времени инструктора | UC-004 | Must |
| FR-047 | Система должна проверять, что изменения доступности не конфликтуют с подтверждёнными занятиями | UC-004 | Must |
| FR-048 | Система должна запрещать изменение доступности при конфликте с подтверждённой записью | UC-004 | Must |
| FR-049 | Система должна пересчитывать доступные слоты после изменения смен или блокировок | UC-004 | Must |

## Бизнес-правила

| ID | Правило | Связанные требования |
|---|---|---|
| BR-001 | Без согласия с пользовательским соглашением запись не создаётся | FR-011, FR-014 |
| BR-002 | Резерв слота держится 15 минут | FR-009, FR-018 |
| BR-003 | Один слот не может быть занят двумя записями | FR-013, FR-014, FR-020 |
| BR-004 | Запись администратором доступна только на текущую дату | FR-032, FR-034 |
