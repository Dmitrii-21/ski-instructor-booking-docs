# DMN-модель принятия решения

## Изменения в BPMN-процессе

Для реализации DMN в исходный BPMN-процесс были внесены изменения: логика определения доступности слотов вынесена из BPMN в отдельную таблицу принятия решений.

## Обоснование использования DMN

На этапе предоставления доступных слотов используется DMN-таблица, которая определяет, может ли конкретный слот быть предложен клиенту.

На вход таблицы подаются уже рассчитанные признаки:

- соответствует ли вид занятия специализации инструктора;
- свободен ли слот;
- доступен ли инструктор;
- подходит ли категория инструктора;
- допустимо ли количество участников;
- хватает ли длительности слота.

На выходе таблица формирует решение о доступности слота и причину отказа.

Такой подход позволяет не перегружать BPMN-схему условиями и выносить изменяемые правила подбора в отдельную модель решений.

## Краткое описание

DMN-таблица «Определить доступность слотов инструкторов» используется для проверки конкретного слота конкретного инструктора на соответствие параметрам запроса клиента.

На вход решения подаются:

- вид занятия;
- специализация инструктора;
- дата занятия;
- дата слота;
- время начала занятия;
- время начала слота;
- продолжительность занятия;
- длительность свободного слота;
- количество человек;
- максимально допустимое количество участников.

Слот считается доступным, если:

- специализация инструктора соответствует выбранному виду занятия;
- дата и время занятия совпадают с параметрами слота;
- продолжительность занятия кратна 30 минутам;
- продолжительность занятия не превышает длительность свободного слота;
- количество человек не превышает максимально допустимое значение.
