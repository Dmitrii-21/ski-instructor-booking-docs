# Спецификация API бэкенда

Backend API используется frontend-приложением для получения данных сценария онлайн-записи и создания записи клиента на занятие.

## Интерактивная спецификация

Интерактивная OpenAPI-документация доступна по ссылке:

[Открыть API Reference](/ski-instructor-booking-docs/api/reference/)

Исходный YAML-файл расположен в репозитории:

```text
my-website/api_specs/backend-openapi.yaml
```

## Основные методы

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/instructor-categories` | Получить категории инструкторов |
| GET | `/api/services` | Получить список услуг |
| GET | `/api/duration` | Получить варианты длительности занятия |
| GET | `/api/group-sizes` | Получить варианты количества участников |
| GET | `/api/skill-levels` | Получить уровни катания |
| GET | `/api/legal/user-agreement` | Получить пользовательское соглашение |
| GET | `/api/instructors` | Получить список инструкторов по параметрам занятия |
| GET | `/api/instructors/{instructorId}/slots` | Получить доступные слоты выбранного инструктора |
| POST | `/api/bookings/hold` | Создать временный резерв слота |
| GET | `/api/bookings/hold/{holdId}` | Получить данные временного резерва |
| POST | `/api/bookings/confirm` | Подтвердить запись клиента на занятие |

## Ключевые сущности API

| Сущность | Назначение |
|---|---|
| `InstructorCategory` | Категория инструктора, например «Лыжи» |
| `Service` | Услуга, доступная для записи |
| `DurationOption` | Вариант длительности занятия |
| `PersonCountOption` | Вариант количества участников |
| `SkillLevel` | Уровень катания клиента |
| `Instructor` | Инструктор, доступный для выбора |
| `AvailabilitySlot` | Временной слот инструктора |
| `BookingHold` | Временное удержание выбранного слота |
| `BookingConfirmRequest` | Запрос на подтверждение записи |
| `BookingConfirmResponse` | Ответ после успешного создания записи |
| `ErrorResponse` | Стандартная структура ошибки API |

## Логика работы API

Сценарий онлайн-записи строится последовательно:

1. Frontend получает справочные данные для первого экрана.
2. Клиент выбирает категорию инструктора, услугу, длительность, количество участников, уровень катания и дату.
3. Frontend запрашивает список подходящих инструкторов.
4. Клиент выбирает инструктора.
5. Frontend запрашивает доступные слоты выбранного инструктора.
6. Клиент выбирает слот.
7. Backend создает временное удержание слота через `POST /api/bookings/hold`.
8. Клиент вводит данные и подтверждает запись.
9. Backend повторно проверяет hold и доступность слота.
10. Backend создает запись и возвращает статус `confirmed`.

## Проверки при подтверждении записи

Перед созданием записи backend проверяет:

- существует ли временное удержание;
- не истекло ли время удержания;
- не был ли слот занят другим клиентом;
- корректны ли данные клиента;
- принято ли пользовательское соглашение.

Если проверки успешны, система создает запись и возвращает клиенту подтверждение.
