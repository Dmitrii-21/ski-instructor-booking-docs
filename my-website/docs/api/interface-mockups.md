# Макеты интерфейса

Ниже представлены макеты интерфейса для сценария онлайн-записи клиента на занятие.

![Макеты интерфейса](/img/interface-mockups.png)

## Назначение макетов

Макеты используются для определения:

- экранов пользовательского сценария;
- данных, необходимых frontend для отображения экранов;
- источников данных и API-методов;
- состояний интерфейса;
- элементов, которые требуют валидации.

## Основные экраны

| Экран | Назначение |
|---|---|
| Выбор параметров занятия | Клиент выбирает категорию инструктора, услугу, длительность, количество участников и дату |
| Выбор инструктора и слота | Клиент выбирает доступного инструктора и свободный слот |
| Ввод данных клиента | Клиент вводит ФИО, телефон, уровень катания и подтверждает согласие |
| Состояние успешной записи | Система показывает результат оформления записи |

## Связь макетов с API

| Экран | Используемые API-методы |
|---|---|
| Выбор параметров занятия | `GET /api/instructor-categories`, `GET /api/services`, `GET /api/duration`, `GET /api/group-sizes`, `GET /api/skill-levels` |
| Выбор инструктора и слота | `GET /api/instructors`, `GET /api/instructors/{instructorId}/slots` |
| Временное удержание слота | `POST /api/bookings/hold`, `GET /api/bookings/hold/{holdId}` |
| Подтверждение записи | `POST /api/bookings/confirm` |

## Основные сущности интерфейса

| Сущность | Назначение |
|---|---|
| `InstructorCategory` | Категория инструктора, например «Лыжи» или «Сноуборд» |
| `Service` | Услуга, выбранная клиентом |
| `DurationOption` | Длительность занятия |
| `PersonCountOption` | Количество участников |
| `SkillLevel` | Уровень катания клиента |
| `Instructor` | Инструктор, доступный для выбора |
| `AvailabilitySlot` | Свободный временной слот |
| `BookingHold` | Временное удержание выбранного слота |
| `BookingConfirmRequest` | Данные для подтверждения записи |
