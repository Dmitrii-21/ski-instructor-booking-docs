Обзор API

Раздел описывает API и интеграционное взаимодействие информационной системы онлайн-записи на занятия с инструкторами горнолыжного курорта.

Основной сценарий API​

  1. Клиент выбирает параметры занятия.
  2. Frontend получает справочные данные: категории инструкторов, услуги, длительности, количество участников и уровни катания.
  3. Frontend получает список инструкторов и доступных слотов.
  4. Клиент выбирает слот.
  5. Backend создает временное удержание слота.
  6. Клиент вводит данные и подтверждает запись.
  7. Backend повторно проверяет доступность слота и создает запись.
  8. Сервис онлайн-записи публикует событие booking.created в RabbitMQ.
  9. Сервис уведомлений получает событие и отправляет уведомление инструктору.
