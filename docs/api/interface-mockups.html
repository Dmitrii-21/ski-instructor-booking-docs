Макеты интерфейса

Ниже представлены макеты интерфейса для сценария онлайн-записи клиента на занятие.

Назначение макетов​

Макеты используются для определения:

  • экранов пользовательского сценария;
  • данных, необходимых frontend для отображения экранов;
  • источников данных и API-методов;
  • состояний интерфейса;
  • элементов, которые требуют валидации.

Основные экраны​

ЭкранНазначение
Выбор параметров занятияКлиент выбирает категорию инструктора, услугу, длительность, количество участников и дату
Выбор инструктора и слотаКлиент выбирает доступного инструктора и свободный слот
Ввод данных клиентаКлиент вводит ФИО, телефон, уровень катания и подтверждает согласие
Состояние успешной записиСистема показывает результат оформления записи

Связь макетов с API​

ЭкранИспользуемые API-методы
Выбор параметров занятияGET /api/instructor-categories, GET /api/services, GET /api/duration, GET /api/group-sizes, GET /api/skill-levels
Выбор инструктора и слотаGET /api/instructors, GET /api/instructors/{instructorId}/slots
Временное удержание слотаPOST /api/bookings/hold, GET /api/bookings/hold/{holdId}
Подтверждение записиPOST /api/bookings/confirm

Основные сущности интерфейса​

СущностьНазначение
InstructorCategoryКатегория инструктора, например «Лыжи» или «Сноуборд»
ServiceУслуга, выбранная клиентом
DurationOptionДлительность занятия
PersonCountOptionКоличество участников
SkillLevelУровень катания клиента
InstructorИнструктор, доступный для выбора
AvailabilitySlotСвободный временной слот
BookingHoldВременное удержание выбранного слота
BookingConfirmRequestДанные для подтверждения записи
